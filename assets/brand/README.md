# Brand assets (sources)

Original artwork; the icons under `build/` are generated from here.

| File                  | Use                                                           |
| --------------------- | ------------------------------------------------------------- |
| `icon-source.png`     | Source of all app icons (`python3 scripts/icons.py`)          |
| `logo.png`            | Logo without wordmark: website, about dialog                  |
| `logo-text-light.png` | Logo with wordmark for light backgrounds (README light theme) |
| `logo-text-dark.png`  | Logo with wordmark for dark backgrounds (README dark theme)   |

Generated by `scripts/icons.py`: `build/appicon.png`, `build/windows/icon.ico`,
`build/darwin/icons.icns` and `build/linux/icons/hicolor/*/apps/gosshpher.png`.

Before the first public release with this artwork, document that Net Inventors GmbH
holds the usage rights to it.
