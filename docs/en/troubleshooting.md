# Troubleshooting

Known problems when building or running GoSSHpher and how to fix them.

| Symptom                                                                               | Cause                                                                                                                                                                     | Fix                                                                                                                                                                                                |
| ------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `wails doctor` / build: `libwebkit` not found, `Package webkit2gtk-4.0 was not found` | Ubuntu 24.04+ and Debian 13 only ship WebKitGTK 4.1                                                                                                                       | `sudo apt install libgtk-3-dev libwebkit2gtk-4.1-dev` and build with `-tags webkit2_41`                                                                                                            |
| `go vet` / `go test` fails with `pattern all:frontend/dist: no matching files found`  | `frontend/dist` missing                                                                                                                                                   | Restore `frontend/dist/.gitignore` (`git checkout -- frontend/dist/.gitignore`) or run `npm run build` in `frontend/`; [vite.config.js](../../frontend/vite.config.js) writes it after every build |
| `go: go.mod requires go >= 1.26.0`                                                    | Go toolchain too old                                                                                                                                                      | Install Go 1.26 or newer                                                                                                                                                                           |
| Console message `Overriding existing handler for signal 10. Set JSC_SIGNAL_FOR_GC …`  | Notice from WebKitGTK's JavaScript engine                                                                                                                                 | Harmless, can be ignored                                                                                                                                                                           |
| macOS: "app cannot be opened because the developer cannot be verified"                | Unsigned build (signing secrets not configured), Gatekeeper                                                                                                               | Right-click → *Open* for own use; configure [code signing](setup.md#code-signing)                                                                                                                  |
| Windows: SmartScreen warning                                                          | Unsigned executable                                                                                                                                                       | *More info* → *Run anyway*; configure [code signing](setup.md#code-signing)                                                                                                                        |
| Linux menu entry shows no icon or a generic one, or the window is not linked to it    | Icon cache not refreshed, or app id and `.desktop` name differ                                                                                                            | Re-run `scripts/install-linux.sh`; log out and in; the window must run with app id `de.netinventors.gosshpher` (set in `main.go`)                                                                  |
| Installed app is outdated after a rebuild                                             | `install-linux.sh` copies the binary                                                                                                                                      | Run `scripts/install-linux.sh` again after `wails build`                                                                                                                                           |
| Save shows "File has changed"                                                         | The file changed on disk since it was loaded (another editor, sync tool)                                                                                                  | *Overwrite* keeps your version, *Reload* discards it                                                                                                                                               |
| More backups than expected next to the config                                         | Only files named `<file>.bak-YYYYMMDD-HHMMSS` are rotated (newest one kept by default); backups with other names are never deleted                                        | Delete other backup files manually                                                                                                                                                                 |
| Settings dialog shows \"The file could not be read\"                                  | `settings.json` is not valid JSON (e.g. edited by hand)                                                                                                                   | Fix the file, or save in the settings dialog to replace it; view settings are not written until then                                                                                               |
| No backups are written                                                                | Backups are disabled in the settings                                                                                                                                      | ⚙ → enable *Create a backup before overwriting*                                                                                                                                                    |
| Effective configuration differs from `ssh -G` for a host                              | `Match exec` results are assumed (default: fails), `localnetwork` and `canonical` are not evaluated; `Include` paths are resolved relative to the edited file's directory | Set the assumption or run the command in the *Match exec* section; compare with `ssh -G <host>`                                                                                                    |
| A hint "File not found" for every key in `config.example`                             | The sample uses fictitious key paths                                                                                                                                      | Expected                                                                                                                                                                                           |
