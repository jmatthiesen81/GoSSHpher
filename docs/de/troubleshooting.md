# Fehlerbehebung

Bekannte Probleme beim Bauen oder Ausführen von GoSSHpher und ihre Lösung.

| Symptom                                                                                            | Ursache                                                                                                                                                                                                            | Lösung                                                                                                                                                                                                                |
| -------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `wails doctor` / Build: `libwebkit` nicht gefunden, `Package webkit2gtk-4.0 was not found`         | Ubuntu 24.04+ und Debian 13 liefern nur noch WebKitGTK 4.1 aus                                                                                                                                                     | `sudo apt install libgtk-3-dev libwebkit2gtk-4.1-dev` und mit `-tags webkit2_41` bauen                                                                                                                                |
| `go vet` / `go test` scheitert mit `pattern all:frontend/dist: no matching files found`            | `frontend/dist` fehlt                                                                                                                                                                                              | `frontend/dist/.gitignore` wiederherstellen (`git checkout -- frontend/dist/.gitignore`) oder `npm run build` in `frontend/` ausführen; [vite.config.js](../../frontend/vite.config.js) schreibt sie nach jedem Build |
| `go: go.mod requires go >= 1.26.0`                                                                 | Go-Toolchain zu alt                                                                                                                                                                                                | Go 1.26 oder neuer installieren                                                                                                                                                                                       |
| Konsolenmeldung `Overriding existing handler for signal 10. Set JSC_SIGNAL_FOR_GC …`               | Hinweis der JavaScript-Engine von WebKitGTK                                                                                                                                                                        | Harmlos, kann ignoriert werden                                                                                                                                                                                        |
| macOS: „App kann nicht geöffnet werden, da der Entwickler nicht verifiziert werden kann“           | Unsignierter Build (Signatur-Secrets nicht eingerichtet), Gatekeeper                                                                                                                                               | Für den Eigenbedarf Rechtsklick → *Öffnen*; [Code-Signing](setup.md#code-signing) einrichten                                                                                                                          |
| Windows: SmartScreen-Warnung                                                                       | Unsigniertes Programm                                                                                                                                                                                              | *Weitere Informationen* → *Trotzdem ausführen*; [Code-Signing](setup.md#code-signing) einrichten                                                                                                                      |
| Linux-Menüeintrag zeigt kein oder ein allgemeines Icon, oder das Fenster wird ihm nicht zugeordnet | Icon-Cache nicht aktualisiert oder App-ID und Name der `.desktop`-Datei weichen ab                                                                                                                                 | `scripts/install-linux.sh` erneut ausführen; ab- und wieder anmelden; das Fenster muss mit der App-ID `de.netinventors.gosshpher` laufen (gesetzt in `main.go`)                                                       |
| Installierte App ist nach einem neuen Build veraltet                                               | `install-linux.sh` kopiert das Binary                                                                                                                                                                              | Nach `wails build` erneut `scripts/install-linux.sh` ausführen                                                                                                                                                        |
| Beim Speichern erscheint „Datei wurde geändert“                                                    | Die Datei wurde seit dem Laden auf der Platte geändert (anderer Editor, Sync-Werkzeug)                                                                                                                             | *Überschreiben* behält die eigene Version, *Neu laden* verwirft sie                                                                                                                                                   |
| Mehr Backups als erwartet neben der Konfiguration                                                  | Rotiert werden nur Dateien namens `<datei>.bak-JJJJMMTT-hhmmss` (standardmäßig bleibt das neueste); Backups mit anderen Namen werden nie gelöscht                                                                  | Andere Backup-Dateien von Hand löschen                                                                                                                                                                                |
| Einstellungsdialog zeigt „Die Datei konnte nicht gelesen werden“                                   | `settings.json` ist kein gültiges JSON (z. B. von Hand bearbeitet)                                                                                                                                                 | Datei korrigieren oder im Einstellungsdialog speichern, um sie zu ersetzen; bis dahin werden keine Ansichtseinstellungen geschrieben                                                                                  |
| Es entstehen keine Backups                                                                         | Backups sind in den Einstellungen abgeschaltet                                                                                                                                                                     | ⚙ → *Vor dem Überschreiben ein Backup anlegen* einschalten                                                                                                                                                            |
| Effektive Konfiguration weicht für einen Host von `ssh -G` ab                                      | Ergebnisse von `Match exec` werden angenommen (Standard: fehlgeschlagen), `localnetwork` und `canonical` werden nicht ausgewertet; `Include`-Pfade werden relativ zum Verzeichnis der bearbeiteten Datei aufgelöst | Annahme setzen oder den Befehl im Abschnitt *Match exec* ausführen; mit `ssh -G <host>` vergleichen                                                                                                                   |
| Hinweis „Datei nicht gefunden“ (bzw. „File not found“) für jeden Schlüssel in `config.example`     | Die Beispieldatei nutzt fiktive Schlüsselpfade                                                                                                                                                                     | Erwartet                                                                                                                                                                                                              |
